Como o EPA é calculado

Cada jogador recebe uma nota de ataque (gols, assistências, xG, xA) e uma de defesa (desarmes, cortes, bloqueios e interceptações). O time tem um pool de vitórias-equivalentes (V + 0,33 × E), dividido meio a meio entre ataque e defesa. O jogador fica com a fatia proporcional à sua nota no time, e EPA = Win Shares × 3. PAA/90 = EPA/90 menos o nível de reposição (0,013). EPA/90 só aparece com pelo menos o mínimo de 90s. Dados: API do Fantasy Premier League, da temporada atual atualizados todo dia. Temporadas anteriores só entram se tiverem as mesmas estatísticas (desarmes e cortes+bloqueios+interceptações existem no FPL a partir de 2025/26).
